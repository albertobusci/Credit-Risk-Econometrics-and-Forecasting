# Credit-Risk-Econometrics-and-Forecasting
Econometric analysis of US and European bank CDS returns using panel regression, PCA, GARCH and Random Forest to identify credit risk drivers and evaluate one-day-ahead forecasts.

## Dataset
The dataset used for the CDS analysis is hosted on Google Drive due to GitHub's file size limitations.
[Download the CDS dataset (CSV)](https://drive.google.com/file/d/1RWhZtPVQLUFEo6pdo8saL3go-qZL-kNJ/view?usp=sharing)
Additional datasets used in the analysis are available directly in this repository.
